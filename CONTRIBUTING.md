# Contributing

## Layout

- `SKILL.md` — the entry workflow agents read. Keep under 500 lines; push detail into `references/`.
- `references/` — production, schema, routing, motion, and stack documents.
- `scripts/` — deterministic tooling (scaffold, validate, captions, finalize, verify, render).
- `assets/templates/` — per-route scene fragments and series furniture.
- `assets/styles/` — design token presets.
- `examples/` — complete runnable projects. Keep them small and reproducible.

## Rules

- Scripts use only the Python standard library plus ffmpeg/ffprobe unless a
  dependency is explicitly optional and probed at runtime.
- Scene templates must be deterministic: no `Math.random()`, no wall-clock
  state, finite animation loops, explicit `fromTo` states.
- Every external asset referenced by an example must ship with the example or
  be generated by code in the example.
- Validate with `python3 scripts/validate_scenes.py examples/sample-project/storyboard/scenes.json`
  before submitting changes to schema or routing.
- Update `CHANGELOG.md` for user-visible changes.
