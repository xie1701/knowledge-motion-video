# visual-concepts.txt — 中文概念 → 英文检索词（素材型风格的查询合成用）
#
# 为什么需要它：Pexels / Pixabay / Openverse / Wikimedia 的检索对英文召回最好，
# 直接拿中文关键词去搜，回来的往往是无关图（实测「智能手机 芯片」返回路由器、麦克风）。
# 这张表把文案里的中文概念映射成英文检索短语，让自动档也能取到对味的素材。
#
# 格式：<中文触发词，用 | 分隔><TAB><英文检索短语，用 | 分隔备选>
# 匹配规则：触发词在场景文案里出现即计分（词越长分越高；若还是该场关键词的一部分，
#          按覆盖率加权）。分数相同则先出现在文案里的胜。
# 取词规则：同一场要几张素材，就按候选表顺位往下取——第一张取第 1 名，第二张取第 2 名，
#          所以每条尽量给 2–4 个语义同域但构图上不同的备选。
#
# 写词规则（三条，都是实测撞出来的）：
#   1. 英文短语必须自带语境。别用 model / scale / cloud / chip 这种单字词——
#      「model scale」实测取回城堡模型照片，「cloud」取回云朵。宁可长一点、限定得死一点。
#   2. 备选要「构图上不同、语义上同域」——同一场四张图都一个样子等于没变。
#   3. **第一顺位必须是「能拍出来的东西」**。抽像名词（inference、algorithm、
#      efficiency、market share）在无密钥素材源上只会命中论文插图和流程图；而取图护栏
#      会把白底图文判掉，于是这一场直接变成「一张都取不到」。先说要拍什么（server rack
#      closeup、stopwatch on desk），抽象词放末尾当兜底。
#
