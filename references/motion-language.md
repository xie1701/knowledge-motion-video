# Motion language

## Scene grammar

Every scene has three phases:

1. **Build** (roughly first 25–35%): reveal the visual subject in semantic order.
2. **Breathe** (middle 35–50%): continue one meaningful action or restrained camera move.
3. **Resolve** (last 20–30%): land the conclusion and hold the final state.

## Visual verbs

Prefer verbs that explain relationships:

- assemble / disassemble;
- connect / disconnect;
- route / filter / rank;
- compare / split / converge;
- reveal / annotate / highlight;
- accumulate / decay / overflow;
- zoom from context to evidence;
- transform one representation into another.

Avoid generic float, pulse, and fade when they do not explain the sentence.

## Narration sync

- Introduce an object just before it is named.
- Land its state change on the payoff word.
- Do not reveal two unrelated ideas simultaneously.
- Keep subtitles independent from scene motion.
- Reserve the final 0.8–1.5 seconds for comprehension.

## Camera

Use camera motion to change information scale:

- push in for evidence or consequence;
- pull back for system context;
- pan between compared regions;
- hold still for a conclusion;
- use hard cuts when the argument changes register.

Do not apply the same slow zoom to every scene.

## Style-specific motion

- Collage: mask reveal, paper slide, parallax, stamp, crop zoom.
- Comic: panel snap, pose replacement, speed lines, reaction hold.
- Paper: layer lift, fold, slot, hinge, top-down assembly, real occlusion.
- Swiss sketch: stroke draw, red registration mark, type lockup, grid-guided pan.
- UI demo: cursor travel, press/release, focus zoom, state before/after.

## Determinism

All motion must be a pure function of composition time. Use explicit start/end states, fixed seeds, finite repeats, local media, and one registered paused timeline in HyperFrames.
